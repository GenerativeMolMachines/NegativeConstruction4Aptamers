# Upstream assets

- The benchmark code uses [MIT](../LICENSE). The [AptaBench data release](https://huggingface.co/datasets/GenerativeMolMachines/AptaBench_dataset), by Mariia Eremeyeva and Nikita Serov, specifies CC BY 4.0.
- [GENA-LM bert-base checkpoint](https://huggingface.co/AIRI-Institute/gena-lm-bert-base). The [GENA-LM source repository](https://github.com/AIRI-Institute/GENA_LM/blob/main/LICENSE) specifies MIT for its code. The original checkpoint card does not explicitly identify a license for those weights.
- [ChemBERTa-zinc-base-v1 checkpoint](https://huggingface.co/seyonec/ChemBERTa-zinc-base-v1). The original checkpoint card does not explicitly identify a weight license.
- [CLAMP](https://github.com/ml-jku/clamp/blob/main/LICENSE) lists separate model terms and GPLv3 for software. The benchmark reads the supplied CLAMP features. It does not distribute the checkpoint.

This repository distributes feature and candidate exports. The MIT license for benchmark code does not establish a license for third-party checkpoints. The original GENA-LM and ChemBERTa checkpoint terms remain unconfirmed.
